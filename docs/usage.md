# 乐读英语记忆曲线复习 APP - 使用说明

## 一、如何运行

1. 用浏览器打开 `app/index.html` 即可使用（推荐 Safari on iOS/iPadOS）。
2. 首次打开后会提示安装 PWA，点击「添加到主屏幕」即可像原生应用一样使用。
3. 所有数据存储在本地 IndexedDB，无需联网。

## 二、如何添加/刷新学习素材

### 方法一：单个文件导入（推荐）

1. 在主界面点击「刷新素材」
2. 选择 `knowledge_base` 目录下的 `.md` 文件
3. 应用会自动解析并增量导入

### 方法二：批量导入

1. 将 Markdown 文件打包或选择多个 `.md` 文件
2. 在刷新素材时选择多个文件
3. 系统会自动去重并显示变更摘要

### 方法三：iPad 文件夹选择（需实测）

- 打开 `safari-picker-test.html` 验证当前 iPad Safari 是否支持 `showDirectoryPicker`
- 若支持，可直接在 App 内选择文件夹
- 若不支持，请使用多文件选择降级方案

## 三、如何备份与恢复数据

### 备份

1. 点击主界面「备份数据」
2. 浏览器会下载一个 JSON 文件
3. 建议定期备份到 iCloud 或电脑

### 恢复

1. 点击主界面「恢复数据」
2. 选择之前备份的 JSON 文件
3. 数据将恢复到备份时的状态

## 四、设置项

- **每日学习时长**：默认 35 分钟，可选 20/35/45 分钟或自定义
- **每日新知识点上限**：默认 10 个
- **自动播放发音**：开启后答题自动朗读单词
- **发音口音**：英式 / 美式
- **语速**：默认 0.8，适合儿童跟读
- **连续答对移除错题**：默认 3 次

## 五、学习流程

1. 点击「开始今日复习」
2. 系统根据 SM-2 记忆曲线算法生成今日学习包
3. 选择答案后立即反馈对错与解析
4. 答错的题目会自动进入错题本
5. 错题本会优先安排复习，连续答对 3 次后移除

## 六、PWA 安装

### iPhone / iPad

1. Safari 中打开 `app/index.html`
2. 点击底部「分享」按钮
3. 选择「添加到主屏幕」
4. 返回桌面即可看到「乐读英语」图标

## 七、注意事项

- 首次使用需要用户交互（点击按钮）才能触发 TTS 发音
- iOS 系统需要安装对应语音包才能正常发音
- 路径：设置 → 辅助功能 → 朗读内容 → 声音 → 下载「英语（英国）」
- 部分 OCR 识别内容可能存在错误，建议先人工校对后再导入

## 八、文件结构

```
app/
├── index.html          # 主页面
├── styles.css          # 样式
├── manifest.json       # PWA 配置
├── sw.js               # Service Worker
├── safari-picker-test.html # Safari 文件夹选择测试
└── js/
    ├── storage.js      # IndexedDB 封装
    ├── parser.js       # Markdown 解析器
    ├── sm2.js          # SM-2 记忆曲线算法
    ├── questions.js    # 题型生成器
    ├── tts.js          # TTS 发音模块
    └── app.js          # 主应用逻辑
```
