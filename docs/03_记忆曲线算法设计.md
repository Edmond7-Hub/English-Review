## 一、算法选型：SM-2 改良版

采用 SuperMemo SM-2 算法的改良版，针对儿童学习场景简化反馈等级：

### 1.1 与原生 SM-2 的差异

| 维度 | 原生 SM-2 | 本应用改良 |
|------|----------|-----------|
| 质量评分 | 0-5 六级 | 简化为3级：不认识(1) / 认识(4) / 熟悉(5) |
| 初始间隔 | I(1)=1, I(2)=6 | I(1)=1, I(2)=3（儿童遗忘更快） |
| 最小EF | 1.3 | 1.3（不变） |
| 最大EF | 无上限 | 3.0（避免间隔过长） |
| 答错处理 | EF下调+重置 | EF下调0.15（比原生更温和，避免儿童挫败感） |
| 状态机 | 无 | 增加 new/learning/review/mastered 状态 |

### 1.2 质量评分映射

```
用户操作              → quality(q)  → 含义
"不认识" / 答错       → q = 1       → 未通过，重置间隔
"认识" / 答对(正常)   → q = 4       → 通过，正常递增间隔
"太简单了" / 答对(快) → q = 5       → 通过，加速递增间隔
```

## 二、核心算法伪代码

### 2.1 SM-2 更新算法

```
function updateSM2(record: ReviewRecord, quality: number): ReviewRecord

  输入:
    record: { interval, ease, reps, lapses, status, ... }
    quality: 1(不认识) | 4(认识) | 5(太简单)

  输出:
    更新后的 record

  --- 算法开始 ---

  // 1. 记录本次复习
  record.lastReview = now()
  record.totalReviews += 1
  if quality >= 4:
    record.totalCorrect += 1

  // 2. 根据质量评分更新
  if quality < 3:  // 答错（不认识）
    record.reps = 0
    record.lapses += 1
    record.interval = 1              // 重置为1天
    record.ease = max(1.3, record.ease - 0.15)  // 温和下调
    record.status = "review"         // 重新进入复习

  else:  // 答对（认识 q=4 或 太简单 q=5）
    record.reps += 1

    // 计算新间隔
    if record.reps == 1:
      record.interval = 1            // 第一次答对：1天后复习
    elif record.reps == 2:
      record.interval = 3            // 第二次：3天后
    elif record.reps == 3:
      record.interval = 7            // 第三次：1周后
    elif record.reps == 4:
      record.interval = 14           // 第四次：2周后
    else:
      record.interval = round(record.interval * record.ease)

    // 更新EF（仅对q=5加速，q=4保持）
    if quality == 5:
      record.ease = min(3.0, record.ease + 0.1)
    // q=4时ease不变

    // 间隔上限：60天（避免过长遗忘）
    record.interval = min(record.interval, 60)

    // 状态更新
    if record.status == "new":
      record.status = "learning"
    elif record.status == "learning":
      record.status = "review"
    elif record.reps >= 5 and record.interval >= 21:
      record.status = "mastered"

  // 3. 计算下次复习时间
  record.nextReview = now() + record.interval * 86400000  // 毫秒

  return record
```

### 2.2 每日计划生成算法

```
function generateDailyPlan(allRecords: ReviewRecord[], settings: Settings, errorRecords: ErrorRecord[]): DailyPlan

  输入:
    allRecords: 所有复习记录
    settings: { dailyDurationMin: 35, maxNewPerDay: 10 }
    errorRecords: 未解决的错题

  输出:
    今日学习计划

  --- 算法开始 ---

  now = currentTime()
  today = formatDate(now, "YYYY-MM-DD")

  // 1. 收集到期复习项（nextReview <= now）
  dueReviews = allRecords.filter(r =>
    r.status != "new" and r.nextReview <= now and r.status != "mastered"
  )

  // 2. 按优先级排序
  //    优先级 = 过期天数（逾期越久越紧急）
  dueReviews.sort((a, b) => {
    overdueA = (now - a.nextReview) / 86400000  // 天
    overdueB = (now - b.nextReview) / 86400000
    return overdueB - overdueA  // 逾期多的排前面
  })

  // 3. 收集新知识点
  newRecords = allRecords.filter(r => r.status == "new")
  newRecords = newRecords.slice(0, settings.maxNewPerDay)  // 不超过每日上限

  // 4. 收集错题巩固项（未解决且上次出错超过1天前）
  errorItems = errorRecords.filter(e =>
    !e.resolved and (now - e.errorTime) > 86400000
  )
  // 错题最多取10个
  errorItems = errorItems.slice(0, 10)

  // 5. 时间估算与裁剪
  //    假设：每个复习项平均45秒，新词平均90秒，错题平均60秒
  avgReviewSec = 45
  avgNewSec = 90
  avgErrorSec = 60
  totalBudgetSec = settings.dailyDurationMin * 60

  // 先放入复习项（优先级最高）
  reviewBudget = dueReviews.length * avgReviewSec
  errorBudget = errorItems.length * avgErrorSec
  remainingBudget = totalBudgetSec - reviewBudget - errorBudget

  // 新词数量 = 剩余预算 / 新词耗时，不超过上限
  newCount = min(
    newRecords.length,
    max(0, floor(remainingBudget / avgNewSec))
  )

  // 6. 如果时间不够，裁剪复习项（保留逾期最久的）
  if reviewBudget + errorBudget > totalBudgetSec:
    // 保留复习项直到预算用完
    maxReview = floor(totalBudgetSec * 0.6 / avgReviewSec)
    dueReviews = dueReviews.slice(0, maxReview)
    // 错题减少
    maxError = floor(totalBudgetSec * 0.2 / avgErrorSec)
    errorItems = errorItems.slice(0, maxError)
    newCount = min(newCount, floor(totalBudgetSec * 0.2 / avgNewSec))

  // 7. 组装计划
  return DailyPlan {
    date: today,
    reviewItems: dueReviews.map(r => {kpId: r.kpId, priority: index}),
    newItems: newRecords.slice(0, newCount).map(r => r.kpId),
    errorItems: errorItems.map(e => e.kpId),
    completed: false,
    results: []
  }
```

### 2.3 错题处理算法

```
function processAnswer(kpId: string, correct: boolean, quality: number, responseMs: number)

  --- 算法开始 ---

  // 1. 更新复习记录（SM-2）
  record = db.getReviewRecord(kpId)
  record = updateSM2(record, quality)
  record.avgResponseMs = (record.avgResponseMs * record.totalReviews + responseMs) / (record.totalReviews + 1)
  db.putReviewRecord(record)

  // 2. 如果答错，记录错题
  if not correct:
    errorRecord = ErrorRecord {
      id: generateUUID(),
      kpId: kpId,
      questionType: currentQuestionType,
      question: currentQuestion,
      userAnswer: currentUserAnswer,
      correctAnswer: correctAnswer,
      errorTime: now(),
      reviewCount: 0,
      consecutiveCorrect: 0,
      resolved: false,
      sessionDate: today
    }
    db.addErrorRecord(errorRecord)

    // 同时重置该知识点已有错题的consecutiveCorrect
    existingErrors = db.getErrorRecords({kpId: kpId, resolved: false})
    for er in existingErrors:
      er.consecutiveCorrect = 0  // 重新计数
      db.updateErrorRecord(er)

  // 3. 如果答对，检查是否在错题巩固中
  else:
    unresolvedErrors = db.getErrorRecords({kpId: kpId, resolved: false})
    for er in unresolvedErrors:
      er.reviewCount += 1
      er.consecutiveCorrect += 1
      if er.consecutiveCorrect >= settings.errorReviewThreshold:  // 默认3次
        er.resolved = true
      db.updateErrorRecord(er)

  // 4. 记录到今日计划结果
  plan = db.getDailyPlan(today)
  plan.results.push({kpId, correct, responseMs, quality})
  db.putDailyPlan(plan)
```

## 三、间隔预览表

以 ease=2.5 为例，每次答对(q=4)的间隔变化：

| 复习次数 | 间隔(天) | 间隔描述 |
|---------|---------|---------|
| 第1次 | 1 | 1天后复习 |
| 第2次 | 3 | 3天后 |
| 第3次 | 7 | 1周后 |
| 第4次 | 14 | 2周后 |
| 第5次 | 35 | 约5周后 (14×2.5) |
| 第6次 | 60 | 上限60天 |
| 第7次+ | 60 | 维持上限 |

答错后重置：interval=1, reps=0, ease-=0.15

function assert(condition, message) {
  if (!condition) throw new Error(`FAIL: ${message}`);

// === 测试1: 首次学习（new → learning）===
function testFirstLearn() {
  let record = {
    status: "new", interval: 0, ease: 2.5, reps: 0,
    lapses: 0, totalReviews: 0, totalCorrect: 0
  };

  record = updateSM2(record, 4);  // 答对

  assert(record.status === "learning", "首次学习后状态应为learning");
  assert(record.reps === 1, "reps应为1");
  assert(record.interval === 1, "首次间隔应为1天");
  assert(record.ease === 2.5, "ease应保持2.5");
  assert(record.totalReviews === 1, "总复习次数应为1");
  assert(record.totalCorrect === 1, "总答对次数应为1");
}

// === 测试2: 连续答对，间隔递增 ===
function testConsecutiveCorrect() {
  let record = {
    status: "review", interval: 1, ease: 2.5, reps: 1,
    lapses: 0, totalReviews: 1, totalCorrect: 1
  };

  // 第二次答对
  record = updateSM2(record, 4);
  assert(record.interval === 3, "第二次间隔应为3天");
  assert(record.reps === 2, "reps应为2");

  // 第三次答对
  record = updateSM2(record, 4);
  assert(record.interval === 7, "第三次间隔应为7天");
  assert(record.reps === 3, "reps应为3");

  // 第四次答对
  record = updateSM2(record, 4);
  assert(record.interval === 14, "第四次间隔应为14天");

  // 第五次答对 (14 * 2.5 = 35)
  record = updateSM2(record, 4);
  assert(record.interval === 35, "第五次间隔应为35天");
  assert(record.reps === 5, "reps应为5");
}

// === 测试3: 答错重置 ===
function testLapse() {

    status: "review", interval: 14, ease: 2.5, reps: 4,

function testDailyPlanBudget() {

  const records = [];
  for (let i = 0; i < 50; i++) {
    records.push({kpId: `review${i}`, status: "review", nextReview: now - 86400000});

  for (let i = 0; i < 20; i++) {
    records.push({kpId: `new${i}`, status: "new", nextReview: 0});

  const settings = {dailyDurationMin: 20, maxNewPerDay: 10};
  const errors = [];

  const plan = generateDailyPlan(records, settings, errors);

  // 20分钟 = 1200秒
  // 复习预算 = 1200 * 0.6 = 720秒 → 720/45 = 16个
  // 错题预算 = 0
  // 新词预算 = 1200 * 0.2 = 240秒 → 240/90 = 2个
  assert(plan.reviewItems.length <= 17, "复习项应被裁剪到16个左右");
  assert(plan.newItems.length <= 3, "新词应被裁剪到2个左右");
}

## 五、算法参数可配置性

所有关键参数在 settings 中可调（家长设置页）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| maxNewPerDay | 10 | 每日新词上限 |
| dailyDurationMin | 35 | 每日总时长 |
| errorReviewThreshold | 3 | 错题移除需连续答对次数 |
| SM-2初始ease | 2.5 | 硬编码，不可调 |
| 间隔阶段表 | [1,3,7,14] | 硬编码，不可调 |
| 间隔上限 | 60天 | 硬编码，不可调 |
| ease下调量 | 0.15 | 硬编码，不可调 |
| ease下限 | 1.3 | 硬编码，不可调 |
