## 三、词汇提取规则验证（按年级）

### 3.1 四年级（格式最完整，可直接解析）

**格式特征：** 编号 + 单词 + 音标 + 词性 + 中文释义 + 搭配短语

```
1. bored
/bɔːd/
adj. 烦闷的; 无聊的
    be bored with…
对……感到厌烦
```

**提取正则：**
```python
# 主词条：编号. 单词 \n /音标/ \n 词性. 中文释义
pattern = r'(\d+)\.\s+(.+?)\n(/[^\n]+/)\n((?:n\.|v\.|adj\.|adv\.|phr\.|num\.|prep\.|conj\.)[^\n]*)\n([^\n]+)'
# 搭配短语：缩进4空格的行 + 下一行中文
collocation_pattern = r'^\s{4,}([^\n]+)\n([^\n]+)'
```

**结构化结果示例：**
```json
{
  "id": "g4_u1_v01",
  "word": "bored",
  "phonetic": "/bɔːd/",
  "pos": "adj.",
  "meaning": "烦闷的; 无聊的",
  "collocations": [{"en": "be bored with…", "zh": "对……感到厌烦"}],
  "unit": "U1", "grade": "4", "term": "3B夏季",
  "section": "vocabulary"
}
```

**验证结果：** ✅ 12个单元全部可解析，规则稳定

### 3.2 三年级春季（格式中等，可解析）

**格式特征：** 编号 + 词组/短语 + 中文（无音标、无词性）

```
1.walk   into    the cafe ⾛进咖啡馆
             out of              ⾛出咖啡馆
2.walk/go   up     the stairs 上楼
```

**提取正则：**
```python
# 主词条：编号. 英文 中文
pattern = r'(\d+)\.\s*([a-zA-Z][a-zA-Z\s/]+?)\s+([\u4e00-\u9fff][^\n]*)'
```

**验证结果：** ✅ 17课可解析，但 L5 等个别文件存在字体编码乱码（如 `CAä s ~}`），需容错处理

### 3.3 二年级（格式简单，可解析）

**格式特征：** 英文 + 中文（无编号、无音标、无词性）

```
street街道
park公园
camera 照相机
```

**提取正则：**
```python
# 英文+中文粘连或空格分隔
pattern = r'([a-zA-Z][a-zA-Z\s]+?)[\s]*([\u4e00-\u9fff][^\n]*)'
```

**验证结果：** ✅ 合集119页可解析，需按课次标题（如"预备二级 秋 L1"）分段

### 3.4 一年级（格式最简单，可解析）

**格式特征：** 纯英文单词列表（无中文释义、无音标、无词性）

```
apple
banana
orange
fruit
```

**提取规则：** 在"单词"标记下、下一个板块标记前，逐行提取纯英文行

**验证结果：** ✅ 可解析，但缺少中文释义和音标，需人工补充或从其他来源补全

### 3.5 不规则动词表（特殊格式，可解析）

**格式特征：** 原形 + 过去式 + 词义（表格结构）

```
cut cut 切、割
run ran 跑步
```

**验证结果：** ✅ 106个不规则动词可解析

## 四、语法提取规则验证（按年级）

### 4.1 四年级（表格对比型语法）

**格式特征：** 语法标题 + 用法对比表格 + 例句

```
n  Hello Grammar-人称代词/物主代词/'s所有格
人称代词：直接指代人或事物的代词。
[表格：单复数 × 人称/物主代词]
's所有格：物品归谁所有
例句：This is Daniel's dancing shoe.
```

**提取规则：** 以 `Hello Grammar` 为分段标记，提取标题行、定义说明、表格行、例句

**验证结果：** ✅ 可解析，表格结构需保留行列对应关系

### 4.2 三年级春季（讲解+练习型语法）

**格式特征：** 语法标题 + 规则讲解 + 句型结构 + 例句 + 练习题

```
Grammar-方位介词+现在进行时
1.位移/移动性介词：表示方位移动
结构：人 + be + 动词ing… + 移动性介词 + 地点
例句：He is getting off the bus at the next stop.
```

**验证结果：** ✅ 可解析，部分课程附带填空练习题可提取为题库

### 4.3 二年级（口诀型语法）

**格式特征：** 语法标题 + 例句 + 用法说明 + 口诀

```
like/likes to...
例句：I like to eat apples!
用法：表达喜欢
口诀：动词遇到他她它，后面要加小尾巴(likes)
```

**验证结果：** ✅ 可解析

### 4.4 一年级（问答句型型语法）

**格式特征：** 问句 + 答句 + 注意事项 + 例句

```
问句：Do you like...?
答句：Yes, I do. / No, I don't.
注意：like后面加可数名词复数或者不可数名词
```

**验证结果：** ✅ 可解析

## 六、关键问题与建议

### 6.1 问题

| # | 问题 | 影响 | 严重度 |
|---|------|------|--------|
| 1 | 三年级秋/冬季知识锦囊为扫描件 | 88个知识点需OCR预处理，文本有噪声 | 高 |
| 2 | 三年级春季部分文件字体编码乱码 | L5等文件部分内容不可读 | 中 |
| 3 | 一二年级无音标、无词性 | TTS发音可正常工作（按单词朗读），但词性信息缺失影响语法题生成 | 中 |
| 4 | 各年级板块结构不统一 | 需为4个年级组分别编写解析器 | 中 |
| 5 | 四年级词汇表(OCR)与知识清单词汇重叠 | 去重逻辑需处理同词不同源的情况 | 低 |

### 6.2 建议

1. **解析优先级：** 四年级 > 三年级春季 > 二年级 > 一年级 > 三年级秋/冬季(OCR)
2. **解析器架构：** 采用策略模式，为每个年级组实现独立的解析器，统一输出同一 JSON Schema
3. **OCR 文本处理：** 三年级秋/冬季 OCR 文本需人工校对关键知识点后入库，或标记为"低置信度"在复习中降低权重
4. **音标补全：** 一二三年级缺失的音标可通过查字典 API 在构建时补全（一次性预处理，非运行时）
5. **增量更新设计：** 知识点唯一 ID 用 `年级_学期_单元_板块_内容哈希` 生成，支持文件变化时的增量比对

### 6.3 可行性结论

**词汇和语法数据可以被正确结构化，但需分年级差异化处理。**

- 四年级和三年级春季（合计 523 词汇 + 50 语法条目）格式规整，可完全自动化解析
- 二年级（352 词汇 + 36 语法条目）格式简单但可解析，缺音标需补全
- 一年级（83 词汇 + 14 语法条目）格式最简，需人工补全中文释义
- 三年级秋/冬季（88 词汇 + 24 语法条目）依赖 OCR 质量，建议人工校对

**建议进入阶段二：数据结构设计。**
