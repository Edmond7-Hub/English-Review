# 剑桥少儿英语每日复习 — 使用说明

> 版本：v1.0 · 共 872 个知识点（词汇 / 短语 / 语法 / 自然拼读 / 不规则动词）
> 适用平台：iOS / iPadOS Safari 浏览器或主屏幕 PWA
> 离线运行：是（首次加载后所有资源被 Service Worker 缓存）

---

## 一、安装与首次启动

### 1. 将应用部署到可访问的位置

由于本应用为纯静态 HTML（无后端），需通过 HTTP 协议访问（不能直接双击 `index.html` 用 `file://` 打开，否则 Service Worker、IndexedDB、TTS 部分功能会受限）。

可选方案：

| 方案 | 适用场景 | 步骤简述 |
| --- | --- | --- |
| **iCloud Drive / 文件 App 同步**（推荐） | iPad 单设备使用 | 将 `app/` 整个文件夹放入 iCloud Drive → 在 iPad "文件" App 中长按 `index.html` → 用 Safari 打开 |
| **本地 Web 服务器**（Mac 端） | 开发调试 | 在 `app/` 目录运行 `python3 -m http.server 8000` → iPad 与 Mac 同 Wi-Fi → Safari 访问 `http://<Mac内网IP>:8000/` |
| **GitHub Pages / 静态托管** | 多设备共享 | 上传 `app/` 文件夹到仓库 → 启用 Pages → Safari 访问发布地址 |

### 2. 首次启动

首次打开时屏幕会显示加载动画，依次完成：
1. 创建 IndexedDB 数据库（6 个 object store）
2. 导入 872 个内置知识点（首次约 3–5 秒）
3. 生成今日学习计划
4. 注册 Service Worker（缓存离线资源）

加载完成后自动跳转首页，即可看到「今日学习」面板。

## 二、添加到 iPad 主屏幕（PWA 模式）

1. 在 **Safari**（不要用 Chrome / 第三方浏览器，它们无法「添加到主屏幕」）中打开应用地址。
2. 点击 Safari 底部工具栏的 **分享按钮**（向上箭头图标）。
3. 在弹出菜单中选择 **「添加到主屏幕」**。
4. 可编辑名称（默认"英语复习"），点击 **「添加」**。
5. 主屏幕会出现紫色"ABC"图标，点击即可全屏启动（无 Safari 地址栏，体验接近原生 App）。

> 提示：PWA 模式下横竖屏均可，应用会记住上次退出位置。

## 三、数据备份与恢复

为防止 Safari 清除网站数据导致学习记录丢失，**强烈建议每周导出一次备份**。

### 导出数据

1. 打开应用 → 底部 Tab 切换到 **「设置」**。
2. 找到 **「数据管理」** 分组 → 点击 **「📤 导出数据」**。
3. 系统会下载一个 JSON 文件，文件名格式为 `english-review-backup-YYYY-MM-DD.json`。
4. 在 iPad 上选择 **「保存到文件 App」**，存到 iCloud Drive 或本地。

### 导入数据（恢复或迁移设备）

1. 进入 **「设置」** → **「数据管理」** → 点击 **「📥 导入数据」**。
2. 在弹出的文件选择器中选中之前导出的 JSON 文件。
3. 确认覆盖提示，导入完成后应用会自动刷新。

> 导入会**合并**而非覆盖：相同 ID 的复习记录以备份文件中较新者为准，新增的知识点会追加进来。

### 重置学习进度

如需清空所有学习记录重新开始：「设置」→「数据管理」→ **「🗑️ 重置学习进度」**（此操作不可撤销，请先导出备份）。

## 四、日常学习流程

### 1. 今日学习（首页）

- **进度环**：显示当日完成度
- **概览三卡**：待复习 / 新词 / 错题数量
- **连续打卡**：完成至少 1 个复习项即记为打卡
- 点击紫色大按钮 **「开始今天的学习」** 进入卡片学习

### 2. 卡片学习（翻转卡片）

- **正面**：单词 + 音标 + 听发音按钮
- **点击卡片**：翻到背面查看释义和例句
- **评分三按钮**：
  - 😵 **不认识** → 10 分钟后再次出现，难度系数下调
  - 😊 **认识** → 间隔按 SM-2 曲线递增（1→3→7→14 天）
  - 🎉 **太简单** → 间隔额外加速，难度系数上调

### 3. 题型练习

卡片学习完成后进入题型练习，包含以下剑桥 YLE 常见题型：

| 题型 | 考察方向 |
| --- | --- |
| 图文匹配（单词 → emoji） | 词汇认读 |
| 单词拼写补全 | 词汇拼写 |
| 选择填空 | 词义辨析 |
| 单选改错 | 语法 |
| 句子排序 | 语法 + 语序 |
| 时态 / 介词填空 | 语法应用 |

- **即时反馈**：每题作答后立即显示对错 + 简短讲解
- **答错自动入错题本**：错题会在后续复习中优先再次出现

### 4. 错题本

- 底部 Tab 切换到 **「错题」**
- 显示：待巩固数 / 已攻克数 / 正确率 + 趋势折线
- 一个知识点**连续答对 3 次**才会从错题本移除
- 错题列表可点击直接重做

### 5. 学习统计

底部 Tab → **「统计」**：
- 今日完成度
- 词汇掌握 / 语法掌握 / 已掌握 / 累计复习次数
- 打卡日历（最近 5 周）
- 正确率折线图（最近 14 天）

## 五、家长设置项

底部 Tab → **「设置」**：

### 学习计划
- **每日学习时长**：20 / 35 / 45 分钟预设，或自定义（5–120 分钟）。默认 35 分钟。
- **每日新词上限**：0–50，默认 10。孩子学太快可下调，太慢可上调。

### 发音（TTS）
- **开启发音**：开关
- **语速**：0.5–1.2，默认 0.8（适合儿童跟读）
- **语音选择**：可指定具体系统语音

> 剑桥少儿英语通常以英式发音为主，建议选择带 `en-GB` 标识的语音。

## 六、系统发音（TTS）安装说明

本应用使用 iOS 内置的 SpeechSynthesis 朗读单词和例句，无需联网。但 iOS 默认可能未安装英式英语语音包，需要手动下载：

### 下载英式英语语音

1. 打开 iPad **「设置」** App
2. 进入 **「辅助功能」** → **「朗读内容」** → **「声音」**
3. 顶部选择 **「英语」**
4. 找到带有 🇬🇧 标识的语音（推荐 **Daniel** 或 **Kate**），点击下载（约 50–150 MB）
5. 下载完成后回到本应用「设置」→「语音选择」下拉中即可看到新语音

### 首次发音无声音？

iOS Safari 出于安全限制，**首次语音合成必须由用户交互触发**。若发现点击「🔊 听发音」按钮没有声音：
- 关闭并重新打开应用
- 再次点击任意发音按钮即可激活
- 激活后整个会话内发音功能可正常使用

## 七、素材增量更新（刷新资料）

> 注意：iOS Safari 对文件夹选择 API 支持有限，本功能在不同 iOS 版本上表现可能不一致。

「乐读」资料持续更新时，可点击「设置」→「数据管理」→「🔄 刷新素材」重新选择资料文件夹。系统会自动比对：

- **新增知识点** → 加入待学习队列，不影响已有计划
- **更新知识点**（释义/例句变化） → 更新内容但**保留记忆曲线记录**
- **移除知识点** → 标记为"已归档"，不硬删除，可在设置中手动清理

刷新完成后会展示一份变更摘要供确认。

## 八、常见问题

### Q1：应用打开是白屏？
- 确保通过 HTTP（非 `file://`）打开
- Safari → 设置 → Safari → 高级 → 启用 Web 检查器，连接 Mac 排查控制台错误

### Q2：学习进度突然全部丢失？
- Safari 在存储空间紧张时会清除未添加到主屏幕的网站数据
- 解决：**添加到主屏幕** + **每周导出备份**

### Q3：发音声音很小或卡顿？
- 检查 iPad 静音开关是否关闭
- 「设置」→「发音」→ 适当调高语速（过慢时部分语音会卡顿）
- 重启应用

### Q4：TTS 语音列表是空的？
- iOS 首次加载语音列表有延迟，可稍等 5–10 秒后重新打开设置页
- 或先下载一个英式语音包（见第六节），列表会立即刷新

### Q5：横屏排版错乱？
- 尝试旋转设备触发重排
- 退出 PWA 重新进入

## 九、文件结构说明

```
app/
├── index.html        # 主页面（包含所有视图结构）
├── style.css         # 全部样式（响应式适配 iPhone/iPad）
├── app.js            # 主逻辑 / UI 控制 / 事件绑定
├── db.js             # IndexedDB 封装（6 个 object store）
├── algorithm.js      # SM-2 改良算法 + 每日计划生成
├── questions.js      # 题型生成（图文匹配 / 拼写 / 排序等）
├── tts.js            # Web Speech Synthesis 封装
├── data.js           # 内联 872 个知识点数据
├── manifest.json     # PWA 清单
└── sw.js             # Service Worker（离线缓存）
```

## 十、技术参数

| 项目 | 值 |
| --- | --- |
| 知识点总数 | 872 |
| 算法 | 改良版 SM-2（3 级评分，间隔阶段 1/3/7/14 天，上限 60 天） |

| 兼容性 | iOS 14+ / iPadOS 14+ Safari |
